# Brand sheets (A4)

One A4 page per flavor: title **Brand Guidelines**, stroke in px, measures in mm, line-height, top:bottom ruler **1:2** (2.5 / 5.0 mm), Drawings **10×8** circle grid at lower right (check = used). Rebuild:

```bash
python3 docs/brand/make_guidelines.py
```

| File | Flavor | Accent (Drawings Dark 1) |
|------|--------|--------------------------|
| `librus-A4.pdf` | LIBRUS | `#6aa84f` Dark green 1 |
| `doutrina-A4.pdf` | DOUTRINA | `#3c78d8` Dark cornflower 1 |
| `centro-A4.pdf` | CENTRO | `#cc0000` Dark red 1 |

CTA (all): `Ache · Leia · Consulte · Anote`. Mailbox: `sergio@doutrina.org` only. Doutrina is the print reference; Librus and Centro have no print set yet.

Lucide names on the sheets: LIBRUS `columns-4` · DOUTRINA `droplet` · CENTRO `house-heart` (paths match `public/brand/*-favicon.svg`).
